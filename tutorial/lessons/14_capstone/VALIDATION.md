# 第十四课验证记录

日期：2026-10-13。测试环境为本机 Godot 4.7.1 stable official、Forward+ / D3D12、NVIDIA GeForce RTX 5060 Ti。本课没有启用第十二课的湍流，不涉及其已知故障路径。

## 已完成的检查

1. 使用 Godot 编辑器导入本课 SVG 资源，记录在 `import.log`。只新增组件资源与课程文件，不更改主场景和全局渲染配置。
2. 实际 GPU 运行 `capstone_lab.tscn -- --lesson-test`，`validation.log` 有 `LESSON_14_TEST_OK`。真实运行同时检查了场景加载、GDScript 和三个 Shader 编译。
3. 四阶段截图已查看：`charge.png`、`release.png`、`impact.png`、`fade.png`；`quality.png` 展示三个质量档位。阶段定位使用测试辅助函数直接设视觉时间，不触发命中计数，不能用截图计数判断信号行为。
4. 自动断言包括：材质对象隔离、A 的颜色、暂停 A 时 B 继续、全局暂停冻结 CPU/GPU、恢复后继续、重播替换旧一轮、零距离播放、强度与范围限制、一次命中/一次自然完成、隐藏后停止模拟、命中回调内重播、自动释放、三个质量档位数量。
5. 自然结束与替换重播采用真实时钟等待验证，不只依赖定位截图。
6. 性能对照使用相同高档、三实例、起终点和种子，唯一差异为核心矩形范围。三轮完整周期测试保留原始样本，最终结果见 `benchmark-example.json`、`benchmark.log` 与 `MEASUREMENTS.md`。

## 测量与图像检查范围

- 初次性能报告只记录逻辑尺寸。复核后最终代码分别记录 `logical_size` 和纹理 API 报告的 `render_target_size`，重新执行性能测试。逻辑画布、纹理报告尺寸、PNG 尺寸并不相同；其具体值与未定位的差异记录在 MEASUREMENTS.md，不混称为同一物理分辨率。
- 每组预热一个完整 2.6 秒周期，再采三个完整周期；中间一轮逆序。VSync 关闭、限帧 240，完成后恢复。
- GPU 指标是主视口渲染计时，包含演示背景/UI；不把它当作组件独占或全部粒子计算时间。
- 优化前后截图固定在视觉时间 1.6，检查场地区域，排除 UI 计数。具体像素差异记录在性能文档，仅代表该截图条件。
- 截图读取安排在计时完成后，不进入采样窗口。

## 静态检查

- `.gd` 按第一课每层一个 Tab，没有空格或混合缩进。
- 检查 Markdown 本地链接、代码围栏、图中命名与实现。
- Mermaid 源码未用独立渲染器渲染，不将语法围栏检查称为图形渲染验证。
- `run_lab.ps1` 做 PowerShell 语法检查。

## 未覆盖及约束

- 未验证其他 GPU、Mobile/Compatibility、导出包、多窗口、任意父节点变换、亮背景或摄像机缩放。
- 未做长期资源增长分析；三个固定槽位重复使用，不代表经过生产级对象池压力测试。
- 未给低、中、高档分别做性能基准；档位做了配置与画面检查，本课性能表只比较高档矩形优化。
- 动态参数只在 play 时采样；目标不跟踪移动，命中不是物理判定。
- 参数类型错误或非有限数字不属于支持范围；起终点有限性由断言检查。
- 没有对测试中途窗口缩放、后台节流、图像或报告写入失败做恢复测试。基准开始前等待窗口稳定，每组结束断言渲染尺寸未变；该检查不能发现改变后又恢复的瞬态变化。报告写入有断言。
- 局部像素图像比较只覆盖一个消散时刻，不能证明所有时刻、后端都逐像素等价。
- 正常取消不发送 finished；free_on_finish 实例在 finished 回调时已排队释放，不能复用。
- 用户学习进度未自动勾选。
