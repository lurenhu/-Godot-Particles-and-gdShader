# 一页设计：奥术冲击

## 使用情境

2D 俯视游戏中的定点奥术法术：从施法点汇聚能量，飞向已确定的目标，再扩散成破碎圆环。先做视觉组件，命中合法性和伤害由游戏逻辑决定。

选择 2D 是为了整合主线课程：第三课程序形状、第四课噪声、第五课淡出、第七至九课自定义运动、第十课实例接口、第十三课测量。本例采用更完整的自定义运动满足 2D 综合要求，不使用屏幕扭曲。

## 时间与视觉优先级

| 标准时间 | 阶段 | 观众应首先看到 |
| --- | --- | --- |
| 0～0.8 s | 蓄力 | 旋入起点的粒子与收缩符文环 |
| 0.8～1.3 s | 释放 | 明确向终点运动的亮核与滞后粒子 |
| 1.3～1.48 s | 命中 | 终点短促亮起、圆环开始扩散 |
| 1.48～2.6 s | 消散 | 径向粒子减速，噪声使圆环破碎后淡出 |

速度为 s 时，总时长约为 `2.6 / s` 秒，受帧粒度影响。范围影响空间半径，不改变持续时间。零距离时仍按完整时间线播放，避免零向量归一化。

## 分层与职责

- `OrbitAndBurst`：一个 GPUParticles2D，自定义模拟完成旋入、随行、径向散开；自定义 CanvasItem Shader 绘制软圆和小圆环。
- `GlyphAndImpact`：一个 ColorRect，自定义 Shader 绘制收缩环、亮核、扩散环；噪声参与颜色和溶解。
- `spell.gd`：拥有唯一时钟、实例参数和生命周期。它不逐颗更新粒子。
- 演示场景：网格、起点/终点标记、UI、三个固定实例槽位、测试与性能记录。

优先保留：起终点关系、四阶段顺序、关键圆环半径和终点消散。允许降低：粒子密度、噪声细节、粒子刷新频率。

## 风格与边界

暗背景、青蓝主色；紫色和金色实例用于验证参数隔离。采用加法混合，适合发光能量；并未验证亮背景下的可读性，不将换色等同于完整火焰或冰霜设计。

初版错误基线：核心图形始终画在 1024×1024 矩形中，大量透明区域仍执行噪声采样。优化版根据效果半径设置紧凑矩形，使用局部像素坐标维持相同形状。两版同时保留用于性能对照，不以减少形状细节冒充同画面优化。

范围以父节点局部像素计。组件支持随父节点做普通 2D 变换，但演示和截图基线采用无缩放父级；缩放后显示像素与本地范围不再一比一。目标在播放开始时采样，不跟踪移动对象。
