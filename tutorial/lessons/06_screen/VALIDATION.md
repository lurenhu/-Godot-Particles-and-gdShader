# 第六课验证记录

环境：Godot 4.7.1 stable，Windows，Forward+ / D3D12，NVIDIA GeForce RTX 5060 Ti。

## 已完成

- 场景与脚本成功加载；实际 GPU 渲染无 Shader 编译错误。
- 运行时检查：两份材质独立、拷贝节点顺序、中间拷贝开关、冻结与继续、中心传参及恢复基线。
- 连续播放进度使用无步长量化的滑块，避免每帧舍入改变播放时长；检查 120 次 1/60 秒推进后进度为 1。
- 查看真实 GPU 截图：共用拷贝、串行拷贝、单波纹遮罩、错误坐标、错误写回以及 1440 × 900 窗口缩放后的画面。初始渲染为 1200 × 800。
- 在 UI 隐藏、成品路径、进度为 1 时，与隐藏两个波纹的背景截图逐字节一致。
- 单波纹基线中，在环带支持范围外加 1 像素余量的区域逐像素与背景一致；环带附近有 7896 个像素发生变化，确认实际产生扭曲。该数量仅记录本次环境，不作为跨硬件标准。
- 初版验证曾把 PNG 灰度为零当作 Shader 遮罩严格为零，因量化产生误判；已改用像素中心到圆心的几何距离判断明确的环带外区域。
- 文档依据 Godot 4.7 官方屏幕读取、CanvasItem 与 BackBufferCopy 文档核对；讲义限制在本课 2D 配置。

## 范围与限制

- 未测量 GPU 性能，也未验证其他渲染器、Camera2D、CanvasLayer 变换或嵌套 SubViewport。
- 点击中心已检查脚本坐标与传参路径；未使用系统鼠标自动化进行端到端点击测试。
- 重叠拷贝对照已检查截图，未建立 GPU 像素的完整数值参考模型。
- 起点零包络依据公式核对；逐像素端点比较覆盖终点 progress = 1。
- 遮罩外背景检查排除了边界外 1 像素的精度过渡带，不声称对浮点临界位置做严格零值证明。
- Mermaid 的代码块与图文已核对，未使用独立 Mermaid 渲染器。
- 本课阶段综合练习留给学习者独立完成，不自动勾选学习进度。
