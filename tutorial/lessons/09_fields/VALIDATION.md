# 第九课验证记录

环境：Godot 4.7.1 stable，Windows，Forward+ / D3D12，NVIDIA GeForce RTX 5060 Ti。截图运行区域 1200 × 800。

## 已完成

- 场景、脚本、模拟与绘制 Shader 成功加载；最终 GPU 日志无编译错误。
- 脚本检查：local_coords 与模拟频率前提、冻结、错误坐标开关、参数恢复。
- 发射器有平移和旋转时，将传入的局部目标再转回全局，与实际目标的距离小于 0.001。
- GPU 检查覆盖吸入、喷散、速度颜色、距离灰度、正确/错误坐标、精确中心出生与 15 Hz 模拟。
- 所有截图时 capture_rect 的位置与尺寸均为有限值，范围没有超过检查阈值；这只是有限采样的包围盒检查，不等于逐粒子 NaN 扫描或任意参数稳定性证明。
- 精确中心出生、零初速、目标与发射器静止时，2 秒后的包围盒为位置 (-24,-24)、尺寸 (48,48)，中心粒子没有飞离。包围盒包含引擎的绘制边界，不等于粒子中心分布直径。
- 60 Hz 吸入基线在模拟 3 秒的包围盒尺寸约 (354.04,340.74)，15 Hz 约 (340.34,336.79)，记录了离散频率差异，不宣称轨迹逐像素相同。
- 实际连续运行：移动并旋转发射器 1.2 秒，改变目标位置，再运行 0.6 秒后冻结并截图，检查范围有限并查看画面。
- UI 增加不透明底板，防止喷散粒子和参考圈干扰控件文字；复核最终移动与速度截图。

## 限制与说明

- `_seek` 用固定目标和发射器变换推进粒子，不能重现它们的历史运动。`transformed.png` 是非零变换下的固定配置对照；`moving.png` 才来自实际连续运动。
- 未对所有粒子逐步回读位置和速度；速度上限、核心零分母保护及加速度有界性同时依据代码核对。
- 中心检查不覆盖非零入射速度的所有组合；仍需通过课程实验观察穿越、绕行与低频率误差。
- 未测试非均匀缩放、跨画布、世界空间模拟、碰撞、其他渲染后端或 GPU 性能。
- 未自动化系统鼠标点击；实际移动目标检查通过设置同一 target_uv 状态路径完成。
- Mermaid 检查图文与代码块，未使用独立渲染器验证。学习进度未自动勾选。
