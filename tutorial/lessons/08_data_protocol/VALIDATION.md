# 第八课验证记录

环境：Godot 4.7.1 stable，Windows，Forward+ / D3D12，NVIDIA GeForce RTX 5060 Ti。截图运行区域 1200 × 800。

## 已完成

- 最终场景、脚本、两份 Shader 与协议 include 成功加载；最终运行和 GPU 日志未报告编译错误。
- 运行时检查：过程与绘制材质隔离、12 个槽位、固定种子配置、冻结、右侧错误开关、INDEX/NUMBER 传参、两侧种子应用及基线恢复。
- GPU 相位视图：从 0.6 秒继续推进同一批粒子 0.4 秒，左侧区域逐字节不变，右侧错误重抽区域变化。
- 相同配置与种子 137 重播到 0.6 秒，左侧相位区域与首次截图一致；改种子 138 后不同。
- NUMBER 模式下，重播后推进到 3.6 秒的第二轮相位与首次 0.6 秒不同。
- INDEX 模式下，首次 0.6 秒与第二轮 3.6 秒的左侧相位区域一致。
- 自然重生年龄检查：在 12 个左侧粒子中心采样，首次与重生后相同生命阶段的年龄灰度差小于 0.02，并处于年轻粒子区间 0.1～0.35，确认年龄没有继承上一轮终值。
- 截图比较按实际渲染尺寸换算区域，排除了顶部 UI 与标题；不把 UI 文字差异当作随机值变化。
- 已查看成品、相位灰度、重生年龄与错误解码的 GPU 实际画面。
- 文档链接、Markdown 代码块闭合已检查；讲义包含 7 张 Mermaid 图。

## 制作时修复的问题

- 初版辅助函数直接访问 RANDOM_SEED 产生编译错误，现由 start/process 作为参数显式传入。
- 初版整数混合常数组合在本机画面中产生全零随机结果；调整为当前整数字面量与混合实现后，分布、跨步和重播检查通过。未将未经独立验证的底层编译器原因作为结论。
- 最终日志已由通过的运行覆盖；脚本成功标记不能单独代替 Shader 编译日志与画面检查。

## 范围与限制

- 相位检查比较渲染后的区域字节，年龄检查读取调试图中心，未直接回读 GPU 原始 CUSTOM 缓冲区。
- 验证限定当前算法、种子、配置和渲染环境；未证明随机函数的统计质量、严格独立性或跨硬件逐像素一致性。
- 相位跨步稳定有图像比较；大小与类型的正确生命周期写入依据代码路径和实际画面核对，未分别建立长期随机统计测试。
- 未测试其他渲染后端、非本地坐标、外部发射、子发射器、序列帧、拖尾或 3D billboard 组合。
- Mermaid 已检查图文与代码块，未使用独立 Mermaid 渲染器。
- 学习进度未自动勾选；独立协议变体留给学习者完成。
